Automated Rules Enforced

The core engine inspects every element in the DOM tree against these 10 predefined accessibility rules:

R-01
Missing Alt Text

Detects <img> tags missing alt attributes or with empty non-decorative descriptions.

R-02
Missing Page Title

Verifies that the document <head> contains a non-empty, descriptive <title>.

R-03
Missing Language Attribute

Confirms the root <html> tag defines a valid lang code for screen reader synthesis.

R-04
Missing Form Labels

Ensures inputs, textareas, and select menus have matching <label for> or aria labels.

R-05
Empty Buttons

Flags <button> elements that lack discernible text, aria-labels, or labeled icons.

R-06
Improper Heading Hierarchy

Checks h1-h6 sequence for skipped levels (e.g. jumping h1 to h3) and missing h1 titles.

R-07
Non-Descriptive Anchor Text

Catches vague link anchors like "click here" or empty links with no discernible target context.

R-08
Missing ARIA Attributes

Identifies interactive elements with click triggers missing keyboard roles, tabindex, or aria states.

R-09
Accessibility HTML Errors

Detects duplicate id attributes across the DOM that break label bindings and ARIA references.

R-10
Color Contrast Minimum

Calculates relative luminance of inline styles, verifying minimum 4.5:1 contrast for normal text.
